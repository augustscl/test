# 数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新报告

## 引言

### 研究背景

数智时代的到来正深刻改变着人类社会的生产方式、生活方式和思维方式。随着人工智能、大数据、云计算、虚拟现实等新兴技术的迅猛发展，数字化、网络化、智能化已成为时代发展的鲜明特征。在这一背景下，高等教育面临着前所未有的挑战与机遇。一方面，数智技术正在重塑教育生态，改变着知识生产、传播和应用的方式；另一方面，作为数字原住民的新生代大学生，其认知特点、学习方式和价值取向也发生了显著变化。这种双重变革对高等教育教学提出了全新要求，传统的教学理念、内容和方法已难以适应数智时代人才培养的需要。

传播学作为研究人类传播活动的学科，其教学更应敏锐把握时代脉搏，积极回应数智变革。《传播学引论》作为新闻传播学专业的基础必修课，承担着学科入门、基础理论构建和专业素养培养的重要使命。然而，当前《传播学引论》课程教学仍存在诸多问题：一是教学内容以西方传播理论为主，中国传统传播智慧挖掘不足，文化自信培养欠缺；二是教学方法以教师讲授为主，学生参与度不高，认知建构不足；三是教学手段单一，未能充分利用数智技术创新教学模式；四是教学评价方式传统，难以全面评估学生的能力发展。这些问题严重制约了《传播学引论》课程的教学效果和人才培养质量。

面对这些挑战，亟需从认知科学和教育技术的前沿理论出发，探索《传播学引论》课程教学的创新路径。基模理论作为认知心理学的重要理论，强调人的认知行为基于已有的心智结构或认知导引结构，为理解学习过程和设计教学活动提供了科学依据。多模态教学则强调通过多种模态（如语言、视觉、听觉、交互等）呈现教学内容，创设丰富的学习环境，满足不同学习风格学生的需求。将基模理论与多模态教学相结合，融入数智技术的创新应用，有望构建一种适应数智时代特点、促进学生认知重塑的新型教学模式。

### 问题意识

本研究基于对数智时代高等教育变革和《传播学引论》课程教学现状的深入思考，提出以下核心问题：

1. **认知重塑问题**：数智时代大学生的认知特点发生了哪些变化？如何基于这些变化重新设计《传播学引论》课程的教学理念和方法？

2. **基模建构问题**：如何运用基模理论指导《传播学引论》课程的教学设计，促进学生传播学认知基模的形成与发展？

3. **多模态教学问题**：如何设计多模态教学活动，创设丰富的学习环境，提升学生的学习体验和效果？

4. **数智融合问题**：如何将数智技术与《传播学引论》课程教学深度融合，实现技术赋能教学的创新突破？

5. **文化传承问题**：如何在《传播学引论》课程中融入中华传统传播智慧，实现中西传播理论的融通创新？

6. **评价创新问题**：如何构建科学有效的教学评价体系，全面评估学生的认知发展和能力提升？

这些问题的提出，旨在突破传统教学模式的局限，探索数智时代《传播学引论》课程教学的创新路径，为培养适应时代发展的高素质传播学人才提供新的思路和方法。

### 研究意义

本研究聚焦数智时代背景下《传播学引论》课程的教学创新，具有重要的理论意义和实践价值：

**理论意义**：

1. **理论融合创新**：本研究将认知心理学中的基模理论与教育学中的多模态教学理念创新融合，构建了"基模导向的多模态教学"新范式，丰富了教学理论体系。

2. **学科交叉探索**：本研究跨越认知科学、教育技术、传播学等多个学科领域，实现了跨学科的理论对话与方法整合，为教学研究提供了新的视角。

3. **本土化理论建构**：本研究注重中华传统传播智慧的挖掘与融入，促进了传播学教学理论的本土化建构，为学科发展提供了新的思路。

**实践价值**：

1. **教学模式创新**：本研究提出的"三维一体"教学模式、"四阶递进"教学流程和"双轨并行"评价体系，为《传播学引论》课程教学提供了可操作的创新方案。

2. **人才培养优化**：本研究设计的基模导向多模态教学方法，有助于提升学生的认知能力、多模态素养和创新思维，优化人才培养质量。

3. **教学实践指导**：本研究提供的教学设计、活动方案和评估方法，为一线教师提供了实用的教学工具和参考，具有较强的推广价值。

4. **数智教育探索**：本研究探索了数智技术与传统学科教学的深度融合路径，为数智时代教育教学变革提供了有益借鉴。

### 研究方法

本研究采用多种研究方法，系统探索《传播学引论》基模导向的多模态教学创新：

1. **文献研究法**：通过广泛收集和分析国内外相关文献，梳理基模理论、多模态教学、数智教育等领域的研究成果，为教学创新提供理论支撑。

2. **调查分析法**：通过问卷调查、访谈等方式，了解数智时代大学生的认知特点和学习需求，分析《传播学引论》课程教学现状和问题。

3. **教学设计法**：基于基模理论和多模态教学理念，设计《传播学引论》课程的教学框架、内容结构、教学活动和评估方法。

4. **比较研究法**：对比分析传统教学模式与创新教学模式的异同，评估创新方案的优势和可行性。

5. **案例分析法**：选取国内外相关教学创新案例进行分析，提炼可借鉴的经验和方法。

### 研究内容

本研究以《传播学引论》课程为研究对象，面向双一流高校本科一年级新闻传播学专业学生，围绕"数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新"这一主题，主要包括以下研究内容：

1. **数智时代认知重塑研究**：分析数智时代大学生认知特点的变化，探讨数智环境对传播学教学的影响和挑战。

2. **基模导向教学理论研究**：阐释基模理论在传播学教学中的应用价值，构建基模导向的教学理论框架。

3. **多模态教学方法研究**：探索多模态教学在《传播学引论》课程中的应用策略，设计多样化的教学活动。

4. **教学创新框架构建**：提出"三维一体"教学模式、"四阶递进"教学流程和"双轨并行"评价体系，构建完整的教学创新框架。

5. **课程内容重构研究**：基于基模理论重构《传播学引论》课程内容，形成"核心基模+拓展模块"的螺旋式上升结构。

6. **教学实施路径研究**：设计教学创新的实施时间表和保障措施，提供可操作的实施方案。

7. **教学评估体系研究**：构建多维度、多层次、多主体的教学评估体系，全面评价教学效果和学生发展。

通过以上研究内容，本研究旨在构建一套系统、科学、可行的《传播学引论》基模导向多模态教学创新方案，为数智时代传播学教学改革提供新的思路和方法，为培养适应时代发展的高素质传播学人才做出贡献。



# 数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新报告

## 第一部分：理论基础与研究现状

### 一、数智时代的认知重塑与教学变革

#### （一）数智时代的特征与挑战

数智时代是以数字化、网络化、智能化为特征的新时代。随着5G、大数据、人工智能、虚拟现实等技术的迅猛发展，人类社会正经历着深刻的数字化转型。这一转型不仅改变了信息的生产、传播和消费方式，也深刻影响着人们的认知结构和思维模式。数智时代的主要特征表现为：

1. **信息爆炸与碎片化**：数字技术使信息生产和传播门槛大幅降低，导致信息量呈指数级增长，同时信息呈现碎片化、多元化特点，对人们的信息获取和处理方式提出挑战。

2. **多模态与沉浸式体验**：数字媒介突破了传统文本限制，通过文字、图像、声音、视频等多种模态呈现信息，创造沉浸式体验，改变了人们的感知方式和体验期待。

3. **人机协同与智能赋能**：人工智能技术深度参与信息处理和知识生产过程，人机协同成为新常态，智能技术赋能人类认知活动。

4. **虚实融合与边界模糊**：虚拟现实、增强现实等技术模糊了物理世界与数字世界的边界，创造了新的存在和交互方式，拓展了人类的认知空间。

这些特征对高等教育带来了深刻挑战：一是知识权威的解构，教师不再是唯一的知识来源；二是学习方式的变革，线性学习向网状学习转变；三是教学场域的拓展，实体课堂与虚拟空间融合；四是教育评价的重构，标准化评价向多元化评价转变。

#### （二）数字原住民的认知特点

当前大学生群体大多出生于2000年后，是典型的"数字原住民"，他们从小在数字环境中成长，形成了独特的认知特点：

1. **多任务处理倾向**：习惯于同时处理多项任务，注意力分散但切换迅速，对单一、线性的学习活动容易产生厌倦。

2. **视觉优先思维**：偏好图像、视频等视觉信息，对纯文本内容的接受度较低，视觉思维占据主导地位。

3. **交互式学习偏好**：习惯于主动参与和即时反馈，对传统单向灌输式教学缺乏耐心，期待互动性强的学习体验。

4. **网络化思维模式**：思维呈现网状结构而非线性结构，善于建立信息间的联系，但系统性思考能力可能不足。

5. **即时满足心理**：习惯于快速获取信息和即时反馈，耐心和深度思考能力有待提升。

6. **协作共享意识**：具有较强的社交网络意识和协作倾向，偏好群体学习和知识共享。

这些认知特点既是教学创新的挑战，也是机遇。传统的教学方式难以满足数字原住民的学习需求，亟需基于其认知特点重新设计教学模式。

#### （三）传播学教学的时代挑战

作为研究人类传播活动的学科，传播学本身正经历着数智时代的深刻变革。一方面，数字技术改变了传播的方式、渠道和效果，催生了网络传播、算法传播、人机传播等新研究领域；另一方面，传播学的研究方法也在数字技术的影响下不断创新，大数据分析、计算传播学等新方法不断涌现。

在这一背景下，《传播学引论》课程教学面临以下挑战：

1. **知识更新挑战**：传统教材和教学内容难以及时反映传播学的最新发展，特别是数智时代的新理论、新现象和新方法。

2. **教学方法挑战**：传统以教师讲授为主的教学方法难以激发数字原住民的学习兴趣和参与度，教学效果受限。

3. **技术应用挑战**：数智技术在传播学教学中的应用仍处于初级阶段，未能充分发挥技术赋能教学的潜力。

4. **文化传承挑战**：西方传播理论在教学中占据主导地位，中国传统传播智慧挖掘不足，文化自信培养欠缺。

5. **能力培养挑战**：传统教学过于注重知识传授，对学生批判性思维、创新能力和实践能力的培养不足。

这些挑战要求我们重新思考《传播学引论》课程的教学理念、内容和方法，探索适应数智时代的教学创新路径。

### 二、基模理论与认知建构

#### （一）基模理论的核心内涵

基模理论（Schema Theory）是认知心理学的重要理论，由皮亚杰（Jean Piaget）提出并经巴特利特（F.C. Bartlett）、鲁梅尔哈特（D.E. Rumelhart）等学者发展完善。该理论认为，人的认知行为基于已有的心智结构或认知导引结构，这种结构被称为"基模"（schema）。

基模理论的核心内涵包括：

1. **基模的定义**：基模是存储在长期记忆中的知识结构，是对概念、事物、事件、行为序列等的抽象表征，是人们理解世界的认知框架。

2. **基模的特性**：基模具有组织性（将相关知识组织成网络结构）、抽象性（是对经验的抽象概括）、动态性（可随新经验不断调整）和引导性（指导信息加工和行为）等特点。

3. **基模的功能**：基模帮助人们选择性地注意信息、解释信息、推断缺失信息、组织记忆和指导行为，是认知活动的基础。

4. **基模的发展**：基模通过同化（将新信息纳入已有基模）和顺应（调整已有基模以适应新信息）两种机制不断发展完善。

基模理论为理解学习过程提供了重要视角：学习不是简单的信息接收，而是基于已有知识结构对新信息进行主动建构的过程。这一理论强调学习者的主体性和已有知识的重要性，为教学设计提供了科学依据。

#### （二）基模理论在教学中的应用

基模理论对教学实践具有重要启示，主要应用包括：

1. **基模激活**：教学开始前激活学生已有的相关基模，帮助学生将新知识与已有知识建立联系。方法包括提问、讨论、案例分析等。

2. **基模诊断**：了解学生已有的知识结构和可能存在的误解，为教学设计提供依据。方法包括前测、概念图绘制、问题解决等。

3. **基模建构**：设计有助于学生形成和发展认知基模的教学活动，促进知识的系统化和结构化。方法包括概念图教学、类比教学、案例教学等。

4. **基模调整**：帮助学生修正不完整或错误的基模，促进认知结构的优化。方法包括认知冲突、反例分析、概念变化教学等。

5. **基模应用**：引导学生在不同情境中应用所学知识，促进基模的灵活性和迁移性。方法包括问题解决、项目学习、情境模拟等。

在传播学教学中，基模理论的应用具有特殊价值。传播学是一门理论性强、概念众多、学派纷呈的学科，学生容易陷入零散知识点的记忆而缺乏系统理解。基于基模理论的教学设计可以帮助学生构建清晰的传播学知识结构，形成对学科的整体认知，提升学习效果。

#### （三）认知建构与知识内化

认知建构是学习者基于已有知识结构，通过主动加工和意义建构，将新知识转化为个人知识的过程。这一过程与基模理论密切相关，涉及以下几个方面：

1. **认知冲突与平衡**：当新信息与已有基模不一致时，产生认知冲突，促使学习者调整认知结构，达到新的平衡。这是认知发展的重要动力。

2. **意义建构与理解**：学习者不是被动接收信息，而是主动赋予信息意义，将其与已有知识联系起来，形成个人化的理解。

3. **知识表征与组织**：学习者以不同方式（如命题、图像、行动等）表征知识，并将知识组织成有意义的结构。

4. **元认知与自我调节**：学习者对自己的认知过程进行监控和调节，反思学习策略和效果，优化认知建构过程。

在《传播学引论》教学中，促进学生的认知建构和知识内化至关重要。这要求教师不仅传授知识，更要创设有利于学生主动建构的学习环境，设计促进认知冲突和平衡的教学活动，引导学生形成个人化的知识理解和组织，培养元认知能力和自我调节能力。

### 三、多模态教学与数智赋能

#### （一）多模态教学的理论基础

多模态教学（Multimodal Teaching）是基于多模态学习理论和多元智能理论发展起来的教学方法，强调通过多种模态（模式）呈现教学内容，创设丰富的学习环境，满足不同学习风格学生的需求。其理论基础主要包括：

1. **多模态学习理论**：由梅耶（Richard Mayer）等人提出，认为人类通过视觉和听觉通道处理信息，多通道学习比单通道学习更有效。当文字、图像、声音等多种模态协同呈现信息时，可以减轻单一通道的认知负荷，提高学习效果。

2. **多元智能理论**：由加德纳（Howard Gardner）提出，认为人类智能是多元的，包括语言智能、逻辑-数学智能、空间智能、音乐智能、身体-动觉智能、人际智能、内省智能和自然观察智能等。不同学生在不同类型的智能上有不同的优势，教学应尊重这种多样性。

3. **符号学理论**：认为不同的符号系统（如语言、图像、声音等）具有不同的表征特性和意义潜力，多种符号系统的协同使用可以创造更丰富的意义。

4. **情境认知理论**：强调学习是在特定情境中进行的社会实践，丰富的情境线索有助于知识的理解和记忆。多模态教学可以创设更真实、丰富的学习情境。

多模态教学的核心理念是：通过多种感官通道和符号系统呈现信息，创造丰富的学习体验，促进深度理解和长期记忆，适应不同学习者的需求和偏好。

#### （二）多模态教学的方法与策略

多模态教学方法丰富多样，主要包括：

1. **多媒体教学法**：综合运用文字、图像、音频、视频等多种媒体呈现教学内容，创造多感官学习体验。如多媒体课件、教学视频、数字故事等。

2. **可视化教学法**：将抽象概念和复杂信息转化为直观的视觉表征，促进理解和记忆。如概念图、思维导图、信息图表、流程图等。

3. **情境模拟教学法**：创设真实或虚拟的情境，让学生在具体情境中学习知识、应用技能。如角色扮演、案例分析、虚拟仿真等。

4. **互动体验教学法**：设计互动性强的学习活动，促进学生主动参与和深度体验。如互动游戏、实验操作、协作项目等。

5. **多感官整合教学法**：有意识地设计整合多种感官的学习活动，如视听结合、触觉体验、动作学习等。

在实施多模态教学时，需要注意以下策略：

1. **模态协同原则**：不同模态应相互支持、协同作用，而非简单叠加或相互干扰。

2. **认知负荷控制**：避免过多模态同时呈现导致认知超载，合理控制信息量和呈现方式。

3. **个性化选择**：为不同学习风格的学生提供多种模态选择，满足个性化需求。

4. **渐进式设计**：从简单到复杂，逐步增加模态的复杂性和整合度。

5. **技术适度原则**：技术应服务于教学目标，避免为技术而技术。

#### （三）数智技术赋能教学创新

数智技术为多模态教学提供了强大支持，主要表现在：

1. **内容呈现的多样化**：数字技术使文字、图像、音频、视频、3D模型、交互式内容等多种形式的教学资源制作和呈现变得更加便捷，极大丰富了教学内容的表现形式。

2. **学习环境的拓展**：虚拟现实（VR）、增强现实（AR）、混合现实（MR）等技术创造了沉浸式学习环境，突破了物理空间的限制，使学生能够体验难以在现实中接触的场景和过程。

3. **交互方式的创新**：触控技术、体感技术、语音交互等使人机交互更加自然和多样化，增强了学习的互动性和参与感。

4. **个性化学习的支持**：人工智能和大数据技术能够分析学生的学习行为和特点，提供个性化的学习路径和资源推荐，实现因材施教。

5. **学习分析的深化**：学习分析技术可以收集和分析学生的学习数据，为教师提供教学决策支持，为学生提供学习反馈，促进教学的精准化和科学化。

在《传播学引论》教学中，数智技术的应用具有特殊价值。传播学本身就与媒介技术密切相关，数智技术不仅是教学手段，也是教学内容的一部分。通过数智技术支持的多模态教学，可以让学生在学习传播理论的同时，亲身体验数字传播的特点和效果，实现理论与实践的统一。

## 第二部分：教学创新设计与实施

### 四、《传播学引论》基模导向的多模态教学创新框架

#### （二）"三维一体"教学模式

基于上述指导思想，本创新构建了"三维一体"的教学模式，即认知维度、模态维度和技术维度三个维度的有机融合：

1. **认知维度**：基于基模理论设计的认知发展路径，包括基模激活、基模重构、基模应用和基模迁移四个阶段。
 - **基模激活**：唤醒学生已有的知识结构和经验，为新知识的接收创造认知基础。
 - **基模重构**：引导学生调整和重组已有认知结构，形成新的知识理解和组织。
 - **基模应用**：在具体情境中应用新形成的认知基模，巩固知识理解和应用能力。
 - **基模迁移**：将知识迁移到新的、复杂的情境中，促进创新思维和问题解决能力。

2. **模态维度**：多种模态协同呈现的教学内容和活动，包括语言模态、视觉模态、听觉模态和交互模态。
 - **语言模态**：包括口头语言和书面语言，是传统教学的主要模态。
 - **视觉模态**：包括图像、图表、视频等视觉呈现形式，强化视觉认知。
 - **听觉模态**：包括音频、音乐等听觉呈现形式，增强听觉体验。
 - **交互模态**：包括操作、体验、互动等形式，促进身体参与和实践体验。

3. **技术维度**：支持教学实施的数智技术应用，包括数字资源、智能工具和虚拟环境。
 - **数字资源**：各类数字化教学内容和学习资源，如电子教材、多媒体课件、数字案例库等。
 - **智能工具**：支持教学和学习的智能化工具，如学习分析系统、智能评价工具、个性化推荐系统等。
 - **虚拟环境**：创设沉浸式学习体验的技术环境，如虚拟现实、增强现实、混合现实等。

这三个维度相互支撑、有机融合，形成了一个立体化的教学模式。认知维度提供了教学设计的理论基础和路径指导，模态维度丰富了教学内容的呈现形式和学习体验，技术维度则为教学实施提供了强大支持和创新可能。

#### （三）"四阶递进"教学流程

基于"三维一体"教学模式，本创新设计了"四阶递进"的教学流程，对应认知维度的四个阶段：

1. **基模唤醒阶段**：
 - **目标**：激活学生已有知识结构，建立认知联系，引发学习兴趣。
 - **活动设计**：多模态情境导入、认知冲突设计、前概念测试、传播现象解读等。
 - **技术支持**：智能推送系统、多媒体展示平台、互动讨论工具等。
 - **教师角色**：情境创设者、问题引导者。
 - **学生角色**：经验分享者、问题探索者。

2. **基模重构阶段**：
 - **目标**：促进学生对核心概念和理论的深度理解，形成系统的知识结构。
 - **活动设计**：多模态知识建构、中西传播智慧对比、数智传播案例分析、传播模型可视化等。
 - **技术支持**：多媒体课件系统、知识图谱工具、3D建模工具等。
 - **教师角色**：知识引导者、思维促进者。
 - **学生角色**：知识建构者、意义创造者。

3. **基模应用阶段**：
 - **目标**：在具体情境中应用所学知识，发展实践能力和问题解决能力。
 - **活动设计**：传播方案设计、多模态传播创作、传播效果分析、传播伦理决策等。
 - **技术支持**：方案设计模板、多媒体创作工具、数据分析软件等。
 - **教师角色**：活动组织者、实践指导者。
 - **学生角色**：方案设计者、内容创作者、问题解决者。

4. **基模迁移阶段**：
 - **目标**：促进知识迁移和创新应用，发展高阶思维能力和创新能力。
 - **活动设计**：跨情境传播实践、学科交叉项目、社会服务学习、创新传播研究等。
 - **技术支持**：项目管理平台、跨学科资源库、研究方法库等。
 - **教师角色**：创新促进者、研究指导者。
 - **学生角色**：创新实践者、研究探索者。

这四个阶段循序渐进、层层深入，形成了一个完整的教学流程。每个阶段都有明确的目标、活动设计、技术支持和师生角色定位，确保教学过程的系统性和有效性。

#### （四）"双轨并行"评价体系

为全面评价教学效果和学生发展，本创新构建了"双轨并行"的评价体系，即形成性评价轨道和总结性评价轨道并行运行：

1. **形成性评价轨道**：贯穿教学全过程，及时反馈学习情况，指导教学调整和学习改进。
 - **课前诊断评估**：评估学生已有知识基础和认知基模，为教学设计提供依据。
 - **课中过程评估**：评估学习活动中的参与表现和阶段性成果，及时调整教学策略。
 - **课后反思评估**：评估学生对学习内容和过程的反思，促进深度学习。
 - **单元整合评估**：评估每个教学单元的学习成果和能力发展，为下一单元教学提供指导。

2. **总结性评价轨道**：在关键节点进行综合评价，全面评估学习成果和能力发展。
 - **认知基模评估**：评估学生传播学认知基模的形成状况，包括概念理解、理论掌握、知识结构等。
 - **能力表现评估**：评估学生的多模态理解能力、传播实践能力、批判性思维能力等。
 - **创新成果评估**：评估学生的创新性学习成果和实践项目，包括创新性、应用价值等。
 - **综合素养评估**：评估学生的综合素养和发展潜力，包括文化自信、社会责任感、国际视野等。

两个评价轨道相互补充、协同作用，形成了全方位、多层次的评价体系。形成性评价注重过程，为学生提供及时反馈和指导；总结性评价注重结果，全面评估学习成效和能力发展。这种双轨并行的评价体系，既符合基模导向教学的理念，又满足了多模态教学的需要，为教学质量的持续提升提供了有力保障。

1. **核心知识基模**：构成传播学学科的基本认知框架，包括三大模块：
 - **传播学基础认知基模**：包括传播的定义、要素、过程、传播理论体系、传播模式等基础知识，构成学科认知的核心框架。
 - **传播类型认知基模**：包括人内传播、人际传播、组织传播、大众传播、跨文化传播等不同传播类型的特点和理论，构成学科认知的类型框架。
 - **传播应用认知基模**：包括传播伦理与法规、传播效果研究、传播与社会变迁、未来传播展望等应用领域，构成学科认知的应用框架。

2. **拓展模块**：围绕核心基模展开的拓展内容，丰富和深化学科认知，包括：
 - **西方视角**：西方传播学的经典理论、研究方法和发展脉络，提供国际化视野。
 - **中国视角**：中国传统传播智慧和当代中国传播理论，增强文化自信和本土意识。
 - **数智视角**：数智时代的传播新理论、新现象和新方法，保持时代前沿性。

这种"核心基模+拓展模块"的结构，既保证了传播学知识体系的系统性和完整性，又实现了中西融合、古今贯通和理实结合，为学生构建清晰、丰富的传播学认知基模提供了有力支持。

#### （三）多模态的内容呈现方式

为促进学生的多通道学习和深度理解，本创新采用多种模态呈现课程内容：

1. **语言模态**：
 - **文本资源**：教材、阅读材料、案例故事等文本内容，提供系统的知识阐述。
 - **口头讲解**：教师讲授、专家访谈、学生汇报等口头表达，促进知识交流和理解。

2. **视觉模态**：
 - **概念图谱**：传播学核心概念的可视化表征，展示概念间的关系和结构。
 - **信息图表**：数据、过程、比较等信息的图形化呈现，增强直观理解。
 - **视频资源**：传播现象、案例分析、专家讲座等视频内容，丰富学习资源。

3. **听觉模态**：
 - **音频讲解**：核心内容的音频讲解，提供灵活的学习方式。
 - **播客节目**：传播学热点话题和案例的播客讨论，拓展学习视野。
 - **音乐元素**：与传播主题相关的音乐作品，创造情境氛围。

4. **交互模态**：
 - **互动练习**：概念理解、理论应用等互动性练习，促进主动参与。
 - **模拟仿真**：传播过程、传播效果等的模拟仿真，创造沉浸式体验。
 - **协作项目**：小组协作完成的传播项目，促进实践应用和协作学习。

这些多模态内容相互补充、协同作用，创造了丰富多样的学习体验，满足了不同学习风格学生的需求，促进了知识的多维度理解和内化。

### 六、基模导向的多模态教学活动设计

#### （一）基模激活型教学活动

基模激活型教学活动旨在唤醒学生已有的知识结构和经验，为新知识的接收创造认知基础。主要活动包括：

1. **多模态情境导入**：
 - **活动描述**：通过视频、音频、图像等多模态资源创设与教学内容相关的真实情境，激活学生已有知识结构。
 - **设计要点**：选择与学生生活经验相关的传播现象，设计引发思考的问题，创造认知冲突。
 - **实施流程**：情境呈现→问题思考→小组讨论→经验分享→教师点评。
 - **案例示范**：以"算法推荐与信息茧房"视频导入"传播效果"单元，引发学生对算法传播影响的思考。

2. **认知冲突设计**：
 - **活动描述**：设计与学生已有认知结构产生冲突的传播现象或案例，引发认知失衡，激发学习动机。
 - **设计要点**：选择具有挑战性的案例，设计反直觉的问题，引导学生发现认知局限。
 - **实施流程**：案例呈现→预测结果→揭示真相→分析差异→反思原因。
 - **案例示范**：呈现"沉默的螺旋"现象的实验结果，挑战学生对舆论形成的直觉认知。

3. **概念图谱构建**：
 - **活动描述**：引导学生绘制反映其已有传播学知识结构的概念图谱，显性化其认知基模。
 - **设计要点**：提供核心概念，设计引导性问题，鼓励自由联想和创造性表达。
 - **实施流程**：概念解释→示例展示→个人绘制→小组分享→集体整合。
 - **案例示范**：以"传播"为核心概念，引导学生绘制包含要素、过程、类型、效果等的概念图谱。

4. **传播现象解读**：
 - **活动描述**：展示当下热点传播现象，引导学生运用已有知识进行初步解读，发现认知局限。
 - **设计要点**：选择时效性强、引人关注的传播现象，设计多角度的解读问题。
 - **实施流程**：现象展示→自主解读→小组讨论→集体分享→教师引导。
 - **案例示范**：展示某热点事件在不同媒体平台的传播轨迹，引导学生分析传播规律和影响因素。

#### （二）基模重构型教学活动

基模重构型教学活动旨在促进学生对核心概念和理论的深度理解，形成系统的知识结构。主要活动包括：

1. **多模态知识建构**：
 - **活动描述**：通过文本、图像、音频、视频等多种模态呈现传播学核心概念和理论，促进深度理解。
 - **设计要点**：选择关键知识点，设计多模态呈现方案，确保不同模态的协同增强。
 - **实施流程**：多模态呈现→概念解析→互动问答→应用示例→概念整合。
 - **案例示范**：通过文本解释、图形模型、案例视频和互动演示多模态呈现"拉斯韦尔5W模式"。

2. **中西传播智慧对比**：
 - **活动描述**：设计西方传播理论与中国传统传播智慧的对比分析活动，促进融合创新的认知基模形成。
 - **设计要点**：选择具有可比性的理论和智慧，设计对比框架，引导发现异同和互补。
 - **实施流程**：理论介绍→对比分析→表格填写→融合思考→创新表达。
 - **案例示范**：对比西方"使用与满足理论"与中国传统"知音"观念，探讨受众主体性的不同表达。

3. **数智传播案例分析**：
 - **活动描述**：选取数智时代典型传播案例，引导学生运用传播理论进行深入分析，更新认知基模。
 - **设计要点**：选择具有代表性的数智传播案例，设计分析框架，引导理论应用。
 - **实施流程**：案例呈现→理论选择→分析讨论→成果汇报→教师点评。
 - **案例示范**：分析短视频平台的传播机制，应用网络传播理论和算法传播理论进行解读。

4. **传播模型可视化**：
 - **活动描述**：利用可视化技术将抽象的传播模型转化为动态、交互的视觉呈现，促进直观理解。
 - **设计要点**：选择关键传播模型，设计动态可视化方案，增加交互性和可操作性。
 - **实施流程**：模型介绍→可视化演示→互动操作→模型比较→应用思考。
 - **案例示范**：通过交互式动画演示"香农-韦弗模型"的信息传递过程，学生可调整参数观察变化。

#### （三）基模应用型教学活动

基模应用型教学活动旨在引导学生在具体情境中应用所学知识，发展实践能力和问题解决能力。主要活动包括：

1. **传播方案设计**：
 - **活动描述**：基于特定传播目标和受众，设计完整的传播方案，应用所学传播理论和方法。
 - **设计要点**：提供真实的传播需求，明确设计要求，鼓励创新思维和理论应用。
 - **实施流程**：需求分析→理论选择→方案设计→方案展示→评价反馈。
 - **案例示范**：为某公益项目设计传播方案，应用受众分析、媒介选择、信息设计等传播理论。

2. **多模态传播创作**：
 - **活动描述**：指导学生运用多种媒介形式创作传播内容，实践多模态传播技能。
 - **设计要点**：明确创作主题和要求，提供技术支持，鼓励多模态整合和创新表达。
 - **实施流程**：主题确定→创作规划→内容制作→作品展示→互评反馈。
 - **案例示范**：创作包含文字、图像、音频、视频的多模态传播作品，传递特定主题信息。

3. **传播效果分析**：
 - **活动描述**：设计传播效果测量与分析活动，应用传播效果理论进行实证研究。
 - **设计要点**：选择可测量的传播案例，提供研究方法指导，强调数据分析和理论应用。
 - **实施流程**：研究设计→数据收集→数据分析→报告撰写→成果展示。
 - **案例示范**：分析某社交媒体传播活动的效果，应用议程设置、意见领袖等理论解释数据。

4. **传播伦理决策**：
 - **活动描述**：设置传播伦理困境情境，引导学生进行伦理分析和决策，应用传播伦理原则。
 - **设计要点**：选择真实的伦理困境案例，设计决策框架，引导多角度思考。
 - **实施流程**：情境呈现→伦理分析→决策制定→决策辩论→反思总结。
 - **案例示范**：分析算法推荐中的伦理困境，从多方利益角度进行决策分析和辩论。

#### （四）基模迁移型教学活动

基模迁移型教学活动旨在促进知识迁移和创新应用，发展高阶思维能力和创新能力。主要活动包括：

1. **跨情境传播实践**：
 - **活动描述**：设计不同情境下的传播任务，引导学生将传播学基模迁移应用于新情境。
 - **设计要点**：选择多样化的传播情境，设置挑战性任务，强调知识迁移和创新应用。
 - **实施流程**：情境设置→任务分析→方案设计→实施反馈→迁移反思。
 - **案例示范**：将传播理论应用于危机传播、健康传播、科学传播等不同领域的实践任务。

2. **学科交叉项目**：
 - **活动描述**：设计传播学与其他学科交叉的项目，促进知识迁移与融合创新。
 - **设计要点**：选择具有交叉性的主题，组建跨学科团队，鼓励多视角思考和创新解决。
 - **实施流程**：主题确定→团队组建→项目设计→项目实施→成果展示。
 - **案例示范**：结合传播学与心理学、社会学、计算机科学等学科，开展跨学科研究项目。

3. **社会服务学习**：
 - **活动描述**：组织面向社会实际需求的传播服务项目，将传播学知识迁移应用于解决实际问题。
 - **设计要点**：选择真实的社会需求，明确服务目标，强调理论应用和社会责任。
 - **实施流程**：需求调研→服务设计→实施服务→效果评估→反思总结。
 - **案例示范**：为社区、公益组织或弱势群体提供传播服务，如设计宣传材料、开展传播培训等。

4. **创新传播研究**：
 - **活动描述**：指导学生开展传播学创新研究，探索传播学前沿问题，促进知识迁移与创新。
 - **设计要点**：提供研究方向指导，培养研究方法，鼓励创新思维和批判精神。
 - **实施流程**：选题确定→文献综述→研究设计→数据收集分析→成果展示。
 - **案例示范**：探索数智时代新兴传播现象，如元宇宙传播、人机传播、算法传播等研究课题。

### 七、基模导向的多模态教学评估方法

#### （一）多维度的评估内容

基于"三维一体"教学模式和"四阶递进"教学流程，本创新构建了多维度的评估内容体系：

1. **认知基模维度**：评价学生传播学认知基模的形成和发展情况。
 - **基模形成度**：评价学生对传播学核心概念和理论的理解准确性和清晰度。
 - **基模完整度**：评价学生传播学知识体系的完整性和系统性。
 - **基模灵活度**：评价学生运用传播学基模分析和解决问题的灵活性。
 - **基模创新度**：评价学生对传播学基模的创新发展和个性化建构。

2. **能力素养维度**：评价学生在学习过程中发展的各项能力和素养。
 - **多模态理解能力**：评价学生通过多种模态理解传播现象的能力。
 - **多模态表达能力**：评价学生运用多种模态进行传播的能力。
 - **传播实践能力**：评价学生在实际情境中应用传播理论的能力。
 - **创新迁移能力**：评价学生将传播学知识迁移应用于新情境的能力。
 - **数智素养**：评价学生适应数智时代的数字素养和信息素养。
 - **人文素养**：评价学生的人文底蕴和文化自信。

3. **情感态度维度**：评价学生的学习投入和价值观形成情况。
 - **学习投入度**：评价学生在学习过程中的参与度和投入程度。
 - **学科认同感**：评价学生对传播学学科的认同感和兴趣。
 - **文化自信心**：评价学生对中华传播智慧的认同和自信。
 - **社会责任感**：评价学生作为传播者的责任意识和伦理观念。

这种多维度的评估内容体系，突破了传统仅关注知识掌握的单一评价模式，全面评价了学生的认知发展、能力提升和情感态度，符合基模导向多模态教学的理念和目标。

#### （二）多元化的评估方法

为全面评价学生的学习过程和成果，本创新采用多元化的评估方法：

1. **认知基模评估方法**：
 - **概念图谱分析**：学生绘制传播学概念图谱，反映其认知基模结构，评价概念间关系的准确性、知识结构的完整性和思维的逻辑性。
 - **多模态理解测试**：设计包含文本、图像、音频、视频等多种模态的理解测试，评价多模态信息的理解能力。
 - **案例分析评估**：学生运用传播学理论分析真实传播案例，评价理论应用的准确性和分析的深度。
 - **基模发展追踪**：通过学期初、中、末三次概念图谱对比，追踪认知基模的发展变化。

2. **能力素养评估方法**：
 - **多模态创作评估**：学生创作多模态传播作品，评价多种模态的整合创新和传播效果。
 - **实践项目评估**：学生完成传播实践项目，评价项目设计的合理性和实施的有效性。
 - **情境模拟评估**：设计传播情境模拟任务，评价学生在真实情境中的表现和应对能力。
 - **数智素养评估**：设计数字工具应用和信息评价任务，评价数字素养和信息素养。

3. **情感态度评估方法**：
 - **学习投入度分析**：通过学习行为数据分析学生的学习投入情况，如学习时间、参与度等。
 - **学习体验调查**：定期开展学习体验和情感态度调查，了解学生的主观感受和态度变化。
 - **反思日志分析**：学生撰写学习反思日志，记录情感体验和态度变化，进行质性分析。
 - **学习档案袋评估**：学生建立个人学习档案袋，记录学习全过程，进行综合评价。

这些多元化的评估方法相互补充、协同作用，既关注结果也关注过程，既有定量评价也有定性分析，为全面了解学生的学习情况和发展状况提供了丰富数据。

#### （三）数智技术支持的评估创新

数智技术为教学评估提供了强大支持，本创新在评估中应用了多种数智技术：

1. **学习分析技术应用**：
 - **学习行为数据采集**：通过学习管理系统采集学生学习行为数据，如学习时间、资源访问、互动参与等。
 - **学习轨迹可视化**：将学生学习数据转化为可视化图表和轨迹，直观展示学习过程和特征。
 - **预测性学习分析**：基于已有数据预测学生学习发展趋势和风险，及早发现问题并提供干预。

2. **人工智能辅助评估**：
 - **自动化评分系统**：利用AI技术对学生作业和测试进行自动评分，提高评估效率和客观性。
 - **文本分析技术**：运用自然语言处理技术分析学生文本作业，提取关键概念、分析逻辑结构。
 - **多模态内容分析**：利用AI技术分析学生创作的多模态内容，评价表达能力和创新水平。

3. **自适应评估系统**：
 - **个性化评估任务**：基于学生特点和学习进展自动生成个性化评估任务，提供精准评估。
 - **实时反馈系统**：在学习过程中提供即时评估反馈，促进学生自我调节和持续改进。
 - **智能推荐系统**：基于评估结果智能推荐学习资源和活动，支持个性化学习路径。

这些数智技术的应用，不仅提高了评估的效率和精准度，也拓展了评估的广度和深度，为教学决策和学生发展提供了有力支持。同时，数智技术的应用本身也是对学生数智素养的培养，实现了评估与教学的有机融合。

### 八、教学创新实施路径与保障

#### （一）分阶段实施路径

为确保教学创新的有效落地，本创新设计了分阶段实施路径：

1. **前期准备阶段（3个月）**：
 - **理论研究与方案完善**：深入研究数智时代认知特点和学生学习需求，细化教学创新方案。
 - **资源建设与技术准备**：开发多模态教学资源，搭建技术支持平台，确保资源和技术就绪。
 - **教师培训与试点准备**：开展教师能力培训，选定试点班级，进行学生前测和需求调研。

2. **实施推进阶段（一学期）**：
 - **初步实施与调整**：开展第一阶段教学活动，收集反馈，及时调整优化。
 - **深化实施与监测**：推进后续教学单元实施，加强过程监测和指导，开展中期评估。
 - **总结评估与成果凝练**：完成全部教学单元，开展总结性评估，整理教学创新成果。

3. **总结优化阶段（2个月）**：
 - **评估分析与经验总结**：全面分析教学效果数据，总结成功经验和存在问题。
 - **方案优化与推广准备**：基于实施经验优化教学方案，准备推广材料和活动。

这种分阶段实施路径，遵循"循序渐进、重点突破、持续优化"的原则，确保教学创新能够科学有序地实施，并在实践中不断完善和发展。

3. **技术保障**：
 - 建立技术支持服务机制

 - 确保技术系统的稳定运行

这些多层次保障措施相互配合、协同作用，为教学创新的顺利实施提供了全方位支持，确保创新目标的实现和教学质量的提升。

#### （三）风险预警与应对

教学创新实施过程中可能面临各种风险和挑战，本创新设计了风险预警与应对机制：

1. **技术风险**：
 - **风险点**：技术平台不稳定或操作复杂，影响教学实施。
 - **预警指标**：系统故障率、用户反馈问题数。
 - **应对措施**：加强技术测试，提供技术支持，准备备用方案。

2. **教师适应风险**：
 - **风险点**：教师对新教学方式适应困难，影响教学效果。
 - **预警指标**：教师反馈问题，教学实施偏差。
 - **应对措施**：强化培训指导，建立教师互助机制，渐进式实施。

3. **学生接受风险**：
 - **风险点**：学生对新教学方式不适应，影响学习效果。
 - **预警指标**：学生参与度，学习满意度。
 - **应对措施**：加强学生引导，提供学习支持，灵活调整节奏。

4. **资源不足风险**：
 - **风险点**：教学资源开发不足或质量不高，影响教学实施。
 - **预警指标**：资源覆盖率，资源质量评价。
 - **应对措施**：优先保障核心资源，引入外部优质资源，建立资源共享机制。

5. **效果不佳风险**：
 - **风险点**：教学创新效果不达预期，影响推广应用。
 - **预警指标**：学习效果评估数据，对比分析结果。
 - **应对措施**：及时分析原因，调整教学策略，强化关键环节。

通过建立风险预警与应对机制，本创新能够及时发现和解决实施过程中的问题，确保教学创新的顺利推进和预期目标的实现。

## 结论

### 一、研究总结

本研究以"数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新"为主题，面向双一流高校本科一年级新闻传播学专业的专业必修课《传播学引论》，探索了适应数智时代特点、促进学生认知重塑的教学创新路径。研究的主要内容和成果可总结如下：

1. **理论基础构建**：本研究深入分析了数智时代的特征与挑战、数字原住民的认知特点和传播学教学的时代挑战，系统阐述了基模理论的核心内涵及其在教学中的应用价值，探讨了多模态教学的理论基础和数智技术赋能教学的创新路径，为教学创新提供了坚实的理论支撑。

2. **创新框架设计**：本研究提出了"三维一体"教学模式、"四阶递进"教学流程和"双轨并行"评价体系，构建了系统化、立体化的教学创新框架。其中，"三维一体"教学模式整合了认知维度、模态维度和技术维度；"四阶递进"教学流程包括基模激活、基模重构、基模应用和基模迁移四个阶段；"双轨并行"评价体系融合了形成性评价和总结性评价两条轨道。

3. **课程内容重构**：本研究基于基模理论重构了《传播学引论》课程内容，形成了"核心基模+拓展模块"的螺旋式上升结构，实现了中西融合、古今贯通和理实结合，并采用多种模态呈现课程内容，创设了丰富的学习环境。

4. **教学活动设计**：本研究设计了基模激活型、基模重构型、基模应用型和基模迁移型四类教学活动，涵盖多模态情境导入、认知冲突设计、多模态知识建构、中西传播智慧对比、传播方案设计、多模态传播创作、跨情境传播实践、学科交叉项目等多种创新活动。

5. **评估方法创新**：本研究构建了多维度的评估内容体系，开发了多元化的评估方法，应用数智技术支持评估创新，实现了对学生认知发展、能力提升和情感态度的全面评价。

6. **实施路径规划**：本研究设计了分阶段实施路径，提出了多层次保障措施，建立了风险预警与应对机制，为教学创新的落地实施提供了可操作的指导方案。

7. **成效与推广分析**：本研究分析了教学创新在学生发展、教学质量、教师发展和学科建设方面的预期成效，探讨了教学创新的理论推广价值、实践推广价值和政策推广价值，并对未来发展进行了展望。

通过以上研究内容和成果，本研究构建了一套系统、科学、可行的《传播学引论》基模导向多模态教学创新方案，为数智时代传播学教学改革提供了新的思路和方法，为培养适应时代发展的高素质传播学人才做出了贡献。

### 二、创新价值

本研究的创新价值主要体现在以下几个方面：

1. **理论创新价值**：
 - 首次将认知心理学中的基模理论与多模态教学理念有机融合，构建了"基模导向的多模态教学"新范式，丰富了教学理论体系。
 - 深入研究数智时代学生认知特点的变化，提出了认知重塑的教学应对策略，为数智时代教学变革提供了理论支撑。
 - 打破西方传播理论主导的学科格局，构建中西融合的传播学知识体系，促进了传播学本土化研究，增强了学科的文化自信和创新活力。

2. **模式创新价值**：
 - 构建了认知维度、模态维度和技术维度三维一体的教学模式，突破了传统单一维度的教学设计，实现了多维度的系统化教学创新。
 - 设计了基模激活、基模重构、基模应用、基模迁移四阶递进的教学流程，将抽象的认知发展过程转化为可操作的教学流程，实现了认知理论的教学转化。
 - 建立了形成性评价与总结性评价双轨并行的评价体系，突破了传统单一结果评价的局限，实现了对学习过程和结果的全面评价。

3. **内容创新价值**：
 - 重构了《传播学引论》课程的知识体系，形成了"核心基模+拓展模块"的螺旋式上升结构，突破了传统知识点罗列式的课程内容组织方式，强调了知识间的关联性和系统性。
 - 运用语言、视觉、听觉、交互等多种模态呈现教学内容，适应了数字原住民多通道学习的特点，增强了学习体验和效果。
 - 及时融入数智时代传播学新理论、新现象和新案例，保持了课程内容的时代性和前沿性，增强了学习内容的实用性和吸引力。

4. **方法创新价值**：
 - 开发了一系列促进认知基模形成与发展的教学方法，将抽象的认知理论转化为具体的教学实践，提高了教学的针对性和有效性。
 - 设计了丰富多样的多模态教学活动，突破了传统单一模态教学的局限，提升了学生的学习参与度和学习效果。
 - 创新性地将数智技术应用于传播学教学的各个环节，实现了技术与教学的深度融合，提升了教学的智能化和个性化水平。

5. **实施创新价值**：
 - 设计了前期准备、实施推进、总结优化三阶段的全程化实施路径，提供了教学创新从理念到实践的完整实施方案，增强了创新的可操作性。
 - 构建了教师、学生、技术人员、管理者多主体协同的实施机制，突破了传统教师单一主体的教学模式，形成了多方参与的教学共同体。
 - 采用持续反馈、不断优化的迭代式实施策略，增强了教学创新的适应性和可持续性，避免了一次性改革的风险。

这些创新价值相互关联、相互支撑，共同构成了本研究的整体创新价值，为数智时代高等教育教学改革提供了有益借鉴和实践指导。

本研究具有重要的理论意义和实践价值：

1. **理论意义**：
 - **教学理论创新**：本研究将认知心理学、教育技术学和传播学等多学科理论融合创新，构建了基模导向多模态教学的理论框架，丰富了教学理论体系，为教学研究提供了新的视角和方法。
 - **学科交叉探索**：本研究跨越认知科学、教育技术、传播学等多个学科领域，实现了跨学科的理论对话与方法整合，促进了学科间的交叉融合和创新发展。
 - **数智教育理论**：本研究探索了数智技术与传统学科教学的深度融合路径，构建了数智赋能的教学模式和评价体系，为数智时代教育理论的发展做出了贡献。
 - **本土化理论建构**：本研究注重中华传统传播智慧的挖掘与融入，促进了传播学教学理论的本土化建构，为学科发展提供了新的思路和方向。

2. **实践价值**：
 - **教学模式创新**：本研究提出的"三维一体"教学模式、"四阶递进"教学流程和"双轨并行"评价体系，为《传播学引论》课程教学提供了可操作的创新方案，可直接指导教学实践。
 - **人才培养优化**：本研究设计的基模导向多模态教学方法，有助于提升学生的认知能力、多模态素养和创新思维，优化人才培养质量，培养适应数智时代发展的高素质传播人才。

 - **数智教育探索**：本研究探索了数智技术与传统学科教学的深度融合路径，为数智时代教育教学变革提供了有益借鉴，推动了教育数字化转型的实践探索。

本研究的理论意义和实践价值相互促进、相得益彰，既推动了教学理论的创新发展，又为教学实践提供了有力指导，对促进高等教育教学质量提升和人才培养模式创新具有重要意义。

### 四、研究局限与展望

尽管本研究在理论构建和实践设计方面做了系统探索，但仍存在一些局限，需要在未来研究中进一步完善：

1. **研究局限**：
 - **实证研究不足**：由于时间和条件限制，本研究主要基于理论分析和设计研究，缺乏大规模的实证数据支持，教学效果的评估主要是预期性的。
 - **个体差异考虑不充分**：本研究在教学设计中虽然考虑了不同学习风格的学生需求，但对学生个体差异的适应性设计还不够细致和深入。
 - **技术应用的深度有限**：受当前技术发展水平和教育应用成熟度的限制，本研究在数智技术的深度应用方面还有提升空间。
 - **跨学科融合有待深化**：本研究在传播学与其他学科的交叉融合方面已有探索，但融合的广度和深度还需进一步拓展。

2. **未来展望**：
 - **深化实证研究**：未来将开展大规模的实证研究，收集和分析教学实施数据，验证和完善教学创新方案，提高研究的科学性和可靠性。
 - **强化个性化教学**：进一步研究学生个体差异特点，开发更加精准的个性化教学策略和方法，实现真正的因材施教和个性化培养。
 - **拓展技术应用**：跟踪人工智能、虚拟现实、元宇宙等前沿技术的发展，探索这些技术在传播学教学中的创新应用，实现技术赋能教学的新突破。
 - **深化跨学科融合**：加强传播学与心理学、社会学、计算机科学、艺术学等学科的交叉融合，拓展研究视野，丰富研究内容，提升研究水平。
 - **推动国际合作**：加强与国际同行的交流与合作，借鉴国际先进经验，共同探索数智时代传播学教学的创新路径，提升研究的国际影响力。

通过认识研究局限、明确未来方向，本研究将不断深化和拓展，为数智时代高等教育教学改革和传播学人才培养做出更大贡献。

数智时代的到来，既为高等教育带来了前所未有的挑战，也提供了难得的创新机遇。面对数字原住民认知特点的变化和传播学学科的时代挑战，教学创新已成为必然选择。本研究以认知科学和教育技术的前沿理论为指导，以《传播学引论》课程为研究对象，构建了基模导向的多模态教学创新方案，旨在促进学生认知重塑，培养适应数智时代发展的高素质传播学人才。

我们相信，通过持续的理论创新和实践探索，通过教育工作者的共同努力，一定能够构建适应数智时代特点、促进学生全面发展的教学新生态，为培养担当民族复兴大任的时代新人做出更大贡献。

# 数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新报告

## 引言

### 研究背景

数智时代的到来正深刻改变着人类社会的生产方式、生活方式和思维方式。随着人工智能、大数据、云计算、虚拟现实等新兴技术的迅猛发展，数字化、网络化、智能化已成为时代发展的鲜明特征。在这一背景下，高等教育面临着前所未有的挑战与机遇。一方面，数智技术正在重塑教育生态，改变着知识生产、传播和应用的方式；另一方面，作为数字原住民的新生代大学生，其认知特点、学习方式和价值取向也发生了显著变化。这种双重变革对高等教育教学提出了全新要求，传统的教学理念、内容和方法已难以适应数智时代人才培养的需要。

传播学作为研究人类传播活动的学科，其教学更应敏锐把握时代脉搏，积极回应数智变革。《传播学引论》作为新闻传播学专业的基础必修课，承担着学科入门、基础理论构建和专业素养培养的重要使命。然而，当前《传播学引论》课程教学仍存在诸多问题：一是教学内容以西方传播理论为主，中国传统传播智慧挖掘不足，文化自信培养欠缺；二是教学方法以教师讲授为主，学生参与度不高，认知建构不足；三是教学手段单一，未能充分利用数智技术创新教学模式；四是教学评价方式传统，难以全面评估学生的能力发展。这些问题严重制约了《传播学引论》课程的教学效果和人才培养质量。

面对这些挑战，亟需从认知科学和教育技术的前沿理论出发，探索《传播学引论》课程教学的创新路径。基模理论作为认知心理学的重要理论，强调人的认知行为基于已有的心智结构或认知导引结构，为理解学习过程和设计教学活动提供了科学依据。多模态教学则强调通过多种模态（如语言、视觉、听觉、交互等）呈现教学内容，创设丰富的学习环境，满足不同学习风格学生的需求。将基模理论与多模态教学相结合，融入数智技术的创新应用，有望构建一种适应数智时代特点、促进学生认知重塑的新型教学模式。

### 问题意识

本研究基于对数智时代高等教育变革和《传播学引论》课程教学现状的深入思考，提出以下核心问题：

1. **认知重塑问题**：数智时代大学生的认知特点发生了哪些变化？如何基于这些变化重新设计《传播学引论》课程的教学理念和方法？

2. **基模建构问题**：如何运用基模理论指导《传播学引论》课程的教学设计，促进学生传播学认知基模的形成与发展？

3. **多模态教学问题**：如何设计多模态教学活动，创设丰富的学习环境，提升学生的学习体验和效果？

4. **数智融合问题**：如何将数智技术与《传播学引论》课程教学深度融合，实现技术赋能教学的创新突破？

5. **文化传承问题**：如何在《传播学引论》课程中融入中华传统传播智慧，实现中西传播理论的融通创新？

6. **评价创新问题**：如何构建科学有效的教学评价体系，全面评估学生的认知发展和能力提升？

## 第一部分：理论基础与研究现状

### 一、数智时代的认知重塑与教学变革

#### （一）数智时代的特征与挑战

数智时代是以数字化、网络化、智能化为特征的新时代。随着5G、大数据、人工智能、虚拟现实等技术的迅猛发展，人类社会正经历着深刻的数字化转型。这一转型不仅改变了信息的生产、传播和消费方式，也深刻影响着人们的认知结构和思维模式。数智时代的主要特征表现为：

1. **信息爆炸与碎片化**：数字技术使信息生产和传播门槛大幅降低，导致信息量呈指数级增长，同时信息呈现碎片化、多元化特点，对人们的信息获取和处理方式提出挑战。

2. **多模态与沉浸式体验**：数字媒介突破了传统文本限制，通过文字、图像、声音、视频等多种模态呈现信息，创造沉浸式体验，改变了人们的感知方式和体验期待。

3. **人机协同与智能赋能**：人工智能技术深度参与信息处理和知识生产过程，人机协同成为新常态，智能技术赋能人类认知活动。

4. **虚实融合与边界模糊**：虚拟现实、增强现实等技术模糊了物理世界与数字世界的边界，创造了新的存在和交互方式，拓展了人类的认知空间。

这些特征对高等教育带来了深刻挑战：一是知识权威的解构，教师不再是唯一的知识来源；二是学习方式的变革，线性学习向网状学习转变；三是教学场域的拓展，实体课堂与虚拟空间融合；四是教育评价的重构，标准化评价向多元化评价转变。

#### （二）数字原住民的认知特点

当前大学生群体大多出生于2000年后，是典型的"数字原住民"，他们从小在数字环境中成长，形成了独特的认知特点：

1. **多任务处理倾向**：习惯于同时处理多项任务，注意力分散但切换迅速，对单一、线性的学习活动容易产生厌倦。

2. **视觉优先思维**：偏好图像、视频等视觉信息，对纯文本内容的接受度较低，视觉思维占据主导地位。

3. **交互式学习偏好**：习惯于主动参与和即时反馈，对传统单向灌输式教学缺乏耐心，期待互动性强的学习体验。

4. **网络化思维模式**：思维呈现网状结构而非线性结构，善于建立信息间的联系，但系统性思考能力可能不足。

5. **即时满足心理**：习惯于快速获取信息和即时反馈，耐心和深度思考能力有待提升。

6. **协作共享意识**：具有较强的社交网络意识和协作倾向，偏好群体学习和知识共享。

这些认知特点既是教学创新的挑战，也是机遇。传统的教学方式难以满足数字原住民的学习需求，亟需基于其认知特点重新设计教学模式。

#### （三）传播学教学的时代挑战

作为研究人类传播活动的学科，传播学本身正经历着数智时代的深刻变革。一方面，数字技术改变了传播的方式、渠道和效果，催生了网络传播、算法传播、人机传播等新研究领域；另一方面，传播学的研究方法也在数字技术的影响下不断创新，大数据分析、计算传播学等新方法不断涌现。

在这一背景下，《传播学引论》课程教学面临以下挑战：

1. **知识更新挑战**：传统教材和教学内容难以及时反映传播学的最新发展，特别是数智时代的新理论、新现象和新方法。

3. **技术应用挑战**：数智技术在传播学教学中的应用仍处于初级阶段，未能充分发挥技术赋能教学的潜力。

### 二、基模理论与认知建构

#### （一）基模理论的核心内涵

基模理论（Schema Theory）是认知心理学的重要理论，由皮亚杰（Jean Piaget）提出并经巴特利特（F.C. Bartlett）、鲁梅尔哈特（D.E. Rumelhart）等学者发展完善。该理论认为，人的认知行为基于已有的心智结构或认知导引结构，这种结构被称为"基模"（schema）。

基模理论的核心内涵包括：

1. **基模的定义**：基模是存储在长期记忆中的知识结构，是对概念、事物、事件、行为序列等的抽象表征，是人们理解世界的认知框架。

2. **基模的特性**：基模具有组织性（将相关知识组织成网络结构）、抽象性（是对经验的抽象概括）、动态性（可随新经验不断调整）和引导性（指导信息加工和行为）等特点。

3. **基模的功能**：基模帮助人们选择性地注意信息、解释信息、推断缺失信息、组织记忆和指导行为，是认知活动的基础。

4. **基模的发展**：基模通过同化（将新信息纳入已有基模）和顺应（调整已有基模以适应新信息）两种机制不断发展完善。

基模理论为理解学习过程提供了重要视角：学习不是简单的信息接收，而是基于已有知识结构对新信息进行主动建构的过程。这一理论强调学习者的主体性和已有知识的重要性，为教学设计提供了科学依据。

#### （二）基模理论在教学中的应用

基模理论对教学实践具有重要启示，主要应用包括：

1. **基模激活**：教学开始前激活学生已有的相关基模，帮助学生将新知识与已有知识建立联系。方法包括提问、讨论、案例分析等。

2. **基模诊断**：了解学生已有的知识结构和可能存在的误解，为教学设计提供依据。方法包括前测、概念图绘制、问题解决等。

3. **基模建构**：设计有助于学生形成和发展认知基模的教学活动，促进知识的系统化和结构化。方法包括概念图教学、类比教学、案例教学等。

4. **基模调整**：帮助学生修正不完整或错误的基模，促进认知结构的优化。方法包括认知冲突、反例分析、概念变化教学等。

5. **基模应用**：引导学生在不同情境中应用所学知识，促进基模的灵活性和迁移性。方法包括问题解决、项目学习、情境模拟等。

在传播学教学中，基模理论的应用具有特殊价值。传播学是一门理论性强、概念众多、学派纷呈的学科，学生容易陷入零散知识点的记忆而缺乏系统理解。基于基模理论的教学设计可以帮助学生构建清晰的传播学知识结构，形成对学科的整体认知，提升学习效果。

#### （三）认知建构与知识内化

认知建构是学习者基于已有知识结构，通过主动加工和意义建构，将新知识转化为个人知识的过程。这一过程与基模理论密切相关，涉及以下几个方面：

1. **认知冲突与平衡**：当新信息与已有基模不一致时，产生认知冲突，促使学习者调整认知结构，达到新的平衡。这是认知发展的重要动力。

2. **意义建构与理解**：学习者不是被动接收信息，而是主动赋予信息意义，将其与已有知识联系起来，形成个人化的理解。

3. **知识表征与组织**：学习者以不同方式（如命题、图像、行动等）表征知识，并将知识组织成有意义的结构。

4. **元认知与自我调节**：学习者对自己的认知过程进行监控和调节，反思学习策略和效果，优化认知建构过程。

在《传播学引论》教学中，促进学生的认知建构和知识内化至关重要。这要求教师不仅传授知识，更要创设有利于学生主动建构的学习环境，设计促进认知冲突和平衡的教学活动，引导学生形成个人化的知识理解和组织，培养元认知能力和自我调节能力。

### 三、多模态教学与数智赋能

#### （一）多模态教学的理论基础

多模态教学（Multimodal Teaching）是基于多模态学习理论和多元智能理论发展起来的教学方法，强调通过多种模态（模式）呈现教学内容，创设丰富的学习环境，满足不同学习风格学生的需求。其理论基础主要包括：

1. **多模态学习理论**：由梅耶（Richard Mayer）等人提出，认为人类通过视觉和听觉通道处理信息，多通道学习比单通道学习更有效。当文字、图像、声音等多种模态协同呈现信息时，可以减轻单一通道的认知负荷，提高学习效果。

2. **多元智能理论**：由加德纳（Howard Gardner）提出，认为人类智能是多元的，包括语言智能、逻辑-数学智能、空间智能、音乐智能、身体-动觉智能、人际智能、内省智能和自然观察智能等。不同学生在不同类型的智能上有不同的优势，教学应尊重这种多样性。

3. **符号学理论**：认为不同的符号系统（如语言、图像、声音等）具有不同的表征特性和意义潜力，多种符号系统的协同使用可以创造更丰富的意义。

4. **情境认知理论**：强调学习是在特定情境中进行的社会实践，丰富的情境线索有助于知识的理解和记忆。多模态教学可以创设更真实、丰富的学习情境。

多模态教学的核心理念是：通过多种感官通道和符号系统呈现信息，创造丰富的学习体验，促进深度理解和长期记忆，适应不同学习者的需求和偏好。

#### （二）多模态教学的方法与策略

多模态教学方法丰富多样，主要包括：

1. **多媒体教学法**：综合运用文字、图像、音频、视频等多种媒体呈现教学内容，创造多感官学习体验。如多媒体课件、教学视频、数字故事等。

2. **可视化教学法**：将抽象概念和复杂信息转化为直观的视觉表征，促进理解和记忆。如概念图、思维导图、信息图表、流程图等。

3. **情境模拟教学法**：创设真实或虚拟的情境，让学生在具体情境中学习知识、应用技能。如角色扮演、案例分析、虚拟仿真等。

4. **互动体验教学法**：设计互动性强的学习活动，促进学生主动参与和深度体验。如互动游戏、实验操作、协作项目等。

5. **多感官整合教学法**：有意识地设计整合多种感官的学习活动，如视听结合、触觉体验、动作学习等。

在实施多模态教学时，需要注意以下策略：

1. **模态协同原则**：不同模态应相互支持、协同作用，而非简单叠加或相互干扰。

2. **认知负荷控制**：避免过多模态同时呈现导致认知超载，合理控制信息量和呈现方式。

3. **个性化选择**：为不同学习风格的学生提供多种模态选择，满足个性化需求。

4. **渐进式设计**：从简单到复杂，逐步增加模态的复杂性和整合度。

5. **技术适度原则**：技术应服务于教学目标，避免为技术而技术。

#### （三）数智技术赋能教学创新

数智技术为多模态教学提供了强大支持，主要表现在：

1. **内容呈现的多样化**：数字技术使文字、图像、音频、视频、3D模型、交互式内容等多种形式的教学资源制作和呈现变得更加便捷，极大丰富了教学内容的表现形式。

2. **学习环境的拓展**：虚拟现实（VR）、增强现实（AR）、混合现实（MR）等技术创造了沉浸式学习环境，突破了物理空间的限制，使学生能够体验难以在现实中接触的场景和过程。

3. **交互方式的创新**：触控技术、体感技术、语音交互等使人机交互更加自然和多样化，增强了学习的互动性和参与感。

4. **个性化学习的支持**：人工智能和大数据技术能够分析学生的学习行为和特点，提供个性化的学习路径和资源推荐，实现因材施教。

5. **学习分析的深化**：学习分析技术可以收集和分析学生的学习数据，为教师提供教学决策支持，为学生提供学习反馈，促进教学的精准化和科学化。

在《传播学引论》教学中，数智技术的应用具有特殊价值。传播学本身就与媒介技术密切相关，数智技术不仅是教学手段，也是教学内容的一部分。通过数智技术支持的多模态教学，可以让学生在学习传播理论的同时，亲身体验数字传播的特点和效果，实现理论与实践的统一。

### 四、《传播学引论》基模导向的多模态教学创新框架

#### （一）教学创新的指导思想

本教学创新以习近平新时代中国特色社会主义思想为指导，全面贯彻党的教育方针，落实立德树人根本任务，坚持"以学生为中心"的教育理念，将传播学专业教育与思想政治教育、创新创业教育有机融合，培养德智体美劳全面发展的社会主义建设者和接班人。

具体指导思想包括：

1. **认知导向**：基于认知科学和学习科学的最新研究成果，关注学生认知发展规律，设计符合认知建构过程的教学活动。

2. **文化自信**：坚持中国立场，挖掘中华优秀传统文化中的传播智慧，促进中西传播理论的融通创新，培养学生的文化自信和家国情怀。

3. **技术赋能**：积极应用数智技术创新教学方式，将技术视为认知工具而非简单的展示手段，实现技术与教学的深度融合。

4. **能力本位**：注重学生核心素养和关键能力的培养，强调知识迁移和创新应用，培养适应数智时代发展的高素质传播人才。

5. **开放融合**：打破学科壁垒，促进传播学与其他学科的交叉融合，培养学生的跨学科思维和综合素养。

#### （二）"三维一体"教学模式

基于上述指导思想，本创新构建了"三维一体"的教学模式，即认知维度、模态维度和技术维度三个维度的有机融合：

1. **认知维度**：基于基模理论设计的认知发展路径，包括基模激活、基模重构、基模应用和基模迁移四个阶段。
 - **基模激活**：唤醒学生已有的知识结构和经验，为新知识的接收创造认知基础。
 - **基模重构**：引导学生调整和重组已有认知结构，形成新的知识理解和组织。
 - **基模应用**：在具体情境中应用新形成的认知基模，巩固知识理解和应用能力。
 - **基模迁移**：将知识迁移到新的、复杂的情境中，促进创新思维和问题解决能力。

2. **模态维度**：多种模态协同呈现的教学内容和活动，包括语言模态、视觉模态、听觉模态和交互模态。
 - **语言模态**：包括口头语言和书面语言，是传统教学的主要模态。
 - **视觉模态**：包括图像、图表、视频等视觉呈现形式，强化视觉认知。
 - **听觉模态**：包括音频、音乐等听觉呈现形式，增强听觉体验。
 - **交互模态**：包括操作、体验、互动等形式，促进身体参与和实践体验。

3. **技术维度**：支持教学实施的数智技术应用，包括数字资源、智能工具和虚拟环境。
 - **数字资源**：各类数字化教学内容和学习资源，如电子教材、多媒体课件、数字案例库等。
 - **智能工具**：支持教学和学习的智能化工具，如学习分析系统、智能评价工具、个性化推荐系统等。
 - **虚拟环境**：创设沉浸式学习体验的技术环境，如虚拟现实、增强现实、混合现实等。

这三个维度相互支撑、有机融合，形成了一个立体化的教学模式。认知维度提供了教学设计的理论基础和路径指导，模态维度丰富了教学内容的呈现形式和学习体验，技术维度则为教学实施提供了强大支持和创新可能。

#### （三）"四阶递进"教学流程

基于"三维一体"教学模式，本创新设计了"四阶递进"的教学流程，对应认知维度的四个阶段：

1. **基模唤醒阶段**：
 - **目标**：激活学生已有知识结构，建立认知联系，引发学习兴趣。
 - **活动设计**：多模态情境导入、认知冲突设计、前概念测试、传播现象解读等。
 - **技术支持**：智能推送系统、多媒体展示平台、互动讨论工具等。
 - **教师角色**：情境创设者、问题引导者。
 - **学生角色**：经验分享者、问题探索者。

2. **基模重构阶段**：
 - **目标**：促进学生对核心概念和理论的深度理解，形成系统的知识结构。
 - **活动设计**：多模态知识建构、中西传播智慧对比、数智传播案例分析、传播模型可视化等。
 - **技术支持**：多媒体课件系统、知识图谱工具、3D建模工具等。
 - **教师角色**：知识引导者、思维促进者。
 - **学生角色**：知识建构者、意义创造者。

3. **基模应用阶段**：
 - **目标**：在具体情境中应用所学知识，发展实践能力和问题解决能力。
 - **活动设计**：传播方案设计、多模态传播创作、传播效果分析、传播伦理决策等。
 - **技术支持**：方案设计模板、多媒体创作工具、数据分析软件等。
 - **教师角色**：活动组织者、实践指导者。
 - **学生角色**：方案设计者、内容创作者、问题解决者。

4. **基模迁移阶段**：
 - **目标**：促进知识迁移和创新应用，发展高阶思维能力和创新能力。
 - **活动设计**：跨情境传播实践、学科交叉项目、社会服务学习、创新传播研究等。
 - **技术支持**：项目管理平台、跨学科资源库、研究方法库等。
 - **教师角色**：创新促进者、研究指导者。
 - **学生角色**：创新实践者、研究探索者。

这四个阶段循序渐进、层层深入，形成了一个完整的教学流程。每个阶段都有明确的目标、活动设计、技术支持和师生角色定位，确保教学过程的系统性和有效性。

#### （四）"双轨并行"评价体系

为全面评价教学效果和学生发展，本创新构建了"双轨并行"的评价体系，即形成性评价轨道和总结性评价轨道并行运行：

1. **形成性评价轨道**：贯穿教学全过程，及时反馈学习情况，指导教学调整和学习改进。
 - **课前诊断评估**：评估学生已有知识基础和认知基模，为教学设计提供依据。
 - **课中过程评估**：评估学习活动中的参与表现和阶段性成果，及时调整教学策略。
 - **课后反思评估**：评估学生对学习内容和过程的反思，促进深度学习。
 - **单元整合评估**：评估每个教学单元的学习成果和能力发展，为下一单元教学提供指导。

2. **总结性评价轨道**：在关键节点进行综合评价，全面评估学习成果和能力发展。
 - **认知基模评估**：评估学生传播学认知基模的形成状况，包括概念理解、理论掌握、知识结构等。
 - **能力表现评估**：评估学生的多模态理解能力、传播实践能力、批判性思维能力等。
 - **创新成果评估**：评估学生的创新性学习成果和实践项目，包括创新性、应用价值等。
 - **综合素养评估**：评估学生的综合素养和发展潜力，包括文化自信、社会责任感、国际视野等。

两个评价轨道相互补充、协同作用，形成了全方位、多层次的评价体系。形成性评价注重过程，为学生提供及时反馈和指导；总结性评价注重结果，全面评估学习成效和能力发展。这种双轨并行的评价体系，既符合基模导向教学的理念，又满足了多模态教学的需要，为教学质量的持续提升提供了有力保障。

### 五、《传播学引论》课程内容的基模导向重构

#### （一）课程内容重构的原则

基于基模理论和多模态教学理念，本创新对《传播学引论》课程内容进行了系统重构，遵循以下原则：

1. **基模导向原则**：以传播学核心概念和理论基模为中心，构建系统化、结构化的知识体系，促进学生认知基模的形成和发展。

2. **中西融合原则**：将西方传播理论与中国传统传播智慧有机融合，促进传播学知识的本土化建构，增强文化自信。

3. **古今贯通原则**：将传统传播与现代传播、数字传播联系起来，呈现传播学发展的历史脉络，培养学生的历史视野。

4. **理实结合原则**：将理论学习与实践应用紧密结合，通过真实案例和实践项目促进知识内化和能力发展。

5. **多模态呈现原则**：运用多种模态呈现教学内容，创设丰富的学习环境，满足不同学习风格学生的需求。

6. **数智融入原则**：及时融入数智时代传播学的新理论、新现象和新方法，保持课程内容的时代性和前沿性。

#### （二）"核心基模+拓展模块"的内容结构

基于上述原则，本创新构建了"核心基模+拓展模块"的螺旋式上升内容结构：

1. **核心知识基模**：构成传播学学科的基本认知框架，包括三大模块：
 - **传播学基础认知基模**：包括传播的定义、要素、过程、传播理论体系、传播模式等基础知识，构成学科认知的核心框架。
 - **传播类型认知基模**：包括人内传播、人际传播、组织传播、大众传播、跨文化传播等不同传播类型的特点和理论，构成学科认知的类型框架。
 - **传播应用认知基模**：包括传播伦理与法规、传播效果研究、传播与社会变迁、未来传播展望等应用领域，构成学科认知的应用框架。

2. **拓展模块**：围绕核心基模展开的拓展内容，丰富和深化学科认知，包括：
 - **西方视角**：西方传播学的经典理论、研究方法和发展脉络，提供国际化视野。
 - **中国视角**：中国传统传播智慧和当代中国传播理论，增强文化自信和本土意识。
 - **数智视角**：数智时代的传播新理论、新现象和新方法，保持时代前沿性。

这种"核心基模+拓展模块"的结构，既保证了传播学知识体系的系统性和完整性，又实现了中西融合、古今贯通和理实结合，为学生构建清晰、丰富的传播学认知基模提供了有力支持。

#### （三）多模态的内容呈现方式

为促进学生的多通道学习和深度理解，本创新采用多种模态呈现课程内容：

1. **语言模态**：
 - **文本资源**：教材、阅读材料、案例故事等文本内容，提供系统的知识阐述。
 - **口头讲解**：教师讲授、专家访谈、学生汇报等口头表达，促进知识交流和理解。

2. **视觉模态**：
 - **概念图谱**：传播学核心概念的可视化表征，展示概念间的关系和结构。
 - **信息图表**：数据、过程、比较等信息的图形化呈现，增强直观理解。
 - **视频资源**：传播现象、案例分析、专家讲座等视频内容，丰富学习资源。

3. **听觉模态**：
 - **音频讲解**：核心内容的音频讲解，提供灵活的学习方式。
 - **播客节目**：传播学热点话题和案例的播客讨论，拓展学习视野。
 - **音乐元素**：与传播主题相关的音乐作品，创造情境氛围。

4. **交互模态**：
 - **互动练习**：概念理解、理论应用等互动性练习，促进主动参与。
 - **模拟仿真**：传播过程、传播效果等的模拟仿真，创造沉浸式体验。
 - **协作项目**：小组协作完成的传播项目，促进实践应用和协作学习。

这些多模态内容相互补充、协同作用，创造了丰富多样的学习体验，满足了不同学习风格学生的需求，促进了知识的多维度理解和内化。

### 六、基模导向的多模态教学活动设计

#### （一）基模激活型教学活动

基模激活型教学活动旨在唤醒学生已有的知识结构和经验，为新知识的接收创造认知基础。主要活动包括：

1. **多模态情境导入**：
 - **活动描述**：通过视频、音频、图像等多模态资源创设与教学内容相关的真实情境，激活学生已有知识结构。
 - **设计要点**：选择与学生生活经验相关的传播现象，设计引发思考的问题，创造认知冲突。
 - **实施流程**：情境呈现→问题思考→小组讨论→经验分享→教师点评。
 - **案例示范**：以"算法推荐与信息茧房"视频导入"传播效果"单元，引发学生对算法传播影响的思考。

2. **认知冲突设计**：
 - **活动描述**：设计与学生已有认知结构产生冲突的传播现象或案例，引发认知失衡，激发学习动机。
 - **设计要点**：选择具有挑战性的案例，设计反直觉的问题，引导学生发现认知局限。
 - **实施流程**：案例呈现→预测结果→揭示真相→分析差异→反思原因。
 - **案例示范**：呈现"沉默的螺旋"现象的实验结果，挑战学生对舆论形成的直觉认知。

3. **概念图谱构建**：
 - **活动描述**：引导学生绘制反映其已有传播学知识结构的概念图谱，显性化其认知基模。
 - **设计要点**：提供核心概念，设计引导性问题，鼓励自由联想和创造性表达。
 - **实施流程**：概念解释→示例展示→个人绘制→小组分享→集体整合。
 - **案例示范**：以"传播"为核心概念，引导学生绘制包含要素、过程、类型、效果等的概念图谱。

4. **传播现象解读**：
 - **活动描述**：展示当下热点传播现象，引导学生运用已有知识进行初步解读，发现认知局限。
 - **设计要点**：选择时效性强、引人关注的传播现象，设计多角度的解读问题。
 - **实施流程**：现象展示→自主解读→小组讨论→集体分享→教师引导。
 - **案例示范**：展示某热点事件在不同媒体平台的传播轨迹，引导学生分析传播规律和影响因素。

#### （二）基模重构型教学活动

基模重构型教学活动旨在促进学生对核心概念和理论的深度理解，形成系统的知识结构。主要活动包括：

1. **多模态知识建构**：
 - **活动描述**：通过文本、图像、音频、视频等多种模态呈现传播学核心概念和理论，促进深度理解。
 - **设计要点**：选择关键知识点，设计多模态呈现方案，确保不同模态的协同增强。
 - **实施流程**：多模态呈现→概念解析→互动问答→应用示例→概念整合。
 - **案例示范**：通过文本解释、图形模型、案例视频和互动演示多模态呈现"拉斯韦尔5W模式"。

2. **中西传播智慧对比**：
 - **活动描述**：设计西方传播理论与中国传统传播智慧的对比分析活动，促进融合创新的认知基模形成。
 - **设计要点**：选择具有可比性的理论和智慧，设计对比框架，引导发现异同和互补。
 - **实施流程**：理论介绍→对比分析→表格填写→融合思考→创新表达。
 - **案例示范**：对比西方"使用与满足理论"与中国传统"知音"观念，探讨受众主体性的不同表达。

3. **数智传播案例分析**：
 - **活动描述**：选取数智时代典型传播案例，引导学生运用传播理论进行深入分析，更新认知基模。
 - **设计要点**：选择具有代表性的数智传播案例，设计分析框架，引导理论应用。
 - **实施流程**：案例呈现→理论选择→分析讨论→成果汇报→教师点评。
 - **案例示范**：分析短视频平台的传播机制，应用网络传播理论和算法传播理论进行解读。

4. **传播模型可视化**：
 - **活动描述**：利用可视化技术将抽象的传播模型转化为动态、交互的视觉呈现，促进直观理解。
 - **设计要点**：选择关键传播模型，设计动态可视化方案，增加交互性和可操作性。
 - **实施流程**：模型介绍→可视化演示→互动操作→模型比较→应用思考。
 - **案例示范**：通过交互式动画演示"香农-韦弗模型"的信息传递过程，学生可调整参数观察变化。

#### （三）基模应用型教学活动

基模应用型教学活动旨在引导学生在具体情境中应用所学知识，发展实践能力和问题解决能力。主要活动包括：

1. **传播方案设计**：
 - **活动描述**：基于特定传播目标和受众，设计完整的传播方案，应用所学传播理论和方法。
 - **设计要点**：提供真实的传播需求，明确设计要求，鼓励创新思维和理论应用。
 - **实施流程**：需求分析→理论选择→方案设计→方案展示→评价反馈。
 - **案例示范**：为某公益项目设计传播方案，应用受众分析、媒介选择、信息设计等传播理论。

2. **多模态传播创作**：
 - **活动描述**：指导学生运用多种媒介形式创作传播内容，实践多模态传播技能。
 - **设计要点**：明确创作主题和要求，提供技术支持，鼓励多模态整合和创新表达。
 - **实施流程**：主题确定→创作规划→内容制作→作品展示→互评反馈。
 - **案例示范**：创作包含文字、图像、音频、视频的多模态传播作品，传递特定主题信息。

3. **传播效果分析**：
 - **活动描述**：设计传播效果测量与分析活动，应用传播效果理论进行实证研究。
 - **设计要点**：选择可测量的传播案例，提供研究方法指导，强调数据分析和理论应用。
 - **实施流程**：研究设计→数据收集→数据分析→报告撰写→成果展示。
 - **案例示范**：分析某社交媒体传播活动的效果，应用议程设置、意见领袖等理论解释数据。

4. **传播伦理决策**：
 - **活动描述**：设置传播伦理困境情境，引导学生进行伦理分析和决策，应用传播伦理原则。
 - **设计要点**：选择真实的伦理困境案例，设计决策框架，引导多角度思考。
 - **实施流程**：情境呈现→伦理分析→决策制定→决策辩论→反思总结。
 - **案例示范**：分析算法推荐中的伦理困境，从多方利益角度进行决策分析和辩论。

#### （四）基模迁移型教学活动

基模迁移型教学活动旨在促进知识迁移和创新应用，发展高阶思维能力和创新能力。主要活动包括：

1. **跨情境传播实践**：
 - **活动描述**：设计不同情境下的传播任务，引导学生将传播学基模迁移应用于新情境。
 - **设计要点**：选择多样化的传播情境，设置挑战性任务，强调知识迁移和创新应用。
 - **实施流程**：情境设置→任务分析→方案设计→实施反馈→迁移反思。
 - **案例示范**：将传播理论应用于危机传播、健康传播、科学传播等不同领域的实践任务。

2. **学科交叉项目**：
 - **活动描述**：设计传播学与其他学科交叉的项目，促进知识迁移与融合创新。
 - **设计要点**：选择具有交叉性的主题，组建跨学科团队，鼓励多视角思考和创新解决。
 - **实施流程**：主题确定→团队组建→项目设计→项目实施→成果展示。
 - **案例示范**：结合传播学与心理学、社会学、计算机科学等学科，开展跨学科研究项目。

3. **社会服务学习**：
 - **活动描述**：组织面向社会实际需求的传播服务项目，将传播学知识迁移应用于解决实际问题。
 - **设计要点**：选择真实的社会需求，明确服务目标，强调理论应用和社会责任。
 - **实施流程**：需求调研→服务设计→实施服务→效果评估→反思总结。
 - **案例示范**：为社区、公益组织或弱势群体提供传播服务，如设计宣传材料、开展传播培训等。

4. **创新传播研究**：
 - **活动描述**：指导学生开展传播学创新研究，探索传播学前沿问题，促进知识迁移与创新。
 - **设计要点**：提供研究方向指导，培养研究方法，鼓励创新思维和批判精神。
 - **实施流程**：选题确定→文献综述→研究设计→数据收集分析→成果展示。
 - **案例示范**：探索数智时代新兴传播现象，如元宇宙传播、人机传播、算法传播等研究课题。

### 七、基模导向的多模态教学评估方法

#### （一）多维度的评估内容

基于"三维一体"教学模式和"四阶递进"教学流程，本创新构建了多维度的评估内容体系：

1. **认知基模维度**：评价学生传播学认知基模的形成和发展情况。
 - **基模形成度**：评价学生对传播学核心概念和理论的理解准确性和清晰度。
 - **基模完整度**：评价学生传播学知识体系的完整性和系统性。
 - **基模灵活度**：评价学生运用传播学基模分析和解决问题的灵活性。
 - **基模创新度**：评价学生对传播学基模的创新发展和个性化建构。

2. **能力素养维度**：评价学生在学习过程中发展的各项能力和素养。
 - **多模态理解能力**：评价学生通过多种模态理解传播现象的能力。
 - **多模态表达能力**：评价学生运用多种模态进行传播的能力。
 - **传播实践能力**：评价学生在实际情境中应用传播理论的能力。
 - **创新迁移能力**：评价学生将传播学知识迁移应用于新情境的能力。
 - **数智素养**：评价学生适应数智时代的数字素养和信息素养。
 - **人文素养**：评价学生的人文底蕴和文化自信。

3. **情感态度维度**：评价学生的学习投入和价值观形成情况。
 - **学习投入度**：评价学生在学习过程中的参与度和投入程度。
 - **学科认同感**：评价学生对传播学学科的认同感和兴趣。
 - **文化自信心**：评价学生对中华传播智慧的认同和自信。
 - **社会责任感**：评价学生作为传播者的责任意识和伦理观念。

这种多维度的评估内容体系，突破了传统仅关注知识掌握的单一评价模式，全面评价了学生的认知发展、能力提升和情感态度，符合基模导向多模态教学的理念和目标。

#### （二）多元化的评估方法

为全面评价学生的学习过程和成果，本创新采用多元化的评估方法：

1. **认知基模评估方法**：
 - **概念图谱分析**：学生绘制传播学概念图谱，反映其认知基模结构，评价概念间关系的准确性、知识结构的完整性和思维的逻辑性。
 - **多模态理解测试**：设计包含文本、图像、音频、视频等多种模态的理解测试，评价多模态信息的理解能力。
 - **案例分析评估**：学生运用传播学理论分析真实传播案例，评价理论应用的准确性和分析的深度。
 - **基模发展追踪**：通过学期初、中、末三次概念图谱对比，追踪认知基模的发展变化。

2. **能力素养评估方法**：
 - **多模态创作评估**：学生创作多模态传播作品，评价多种模态的整合创新和传播效果。
 - **实践项目评估**：学生完成传播实践项目，评价项目设计的合理性和实施的有效性。
 - **情境模拟评估**：设计传播情境模拟任务，评价学生在真实情境中的表现和应对能力。
 - **数智素养评估**：设计数字工具应用和信息评价任务，评价数字素养和信息素养。

3. **情感态度评估方法**：
 - **学习投入度分析**：通过学习行为数据分析学生的学习投入情况，如学习时间、参与度等。
 - **学习体验调查**：定期开展学习体验和情感态度调查，了解学生的主观感受和态度变化。
 - **反思日志分析**：学生撰写学习反思日志，记录情感体验和态度变化，进行质性分析。
 - **学习档案袋评估**：学生建立个人学习档案袋，记录学习全过程，进行综合评价。

这些多元化的评估方法相互补充、协同作用，既关注结果也关注过程，既有定量评价也有定性分析，为全面了解学生的学习情况和发展状况提供了丰富数据。

#### （三）数智技术支持的评估创新

数智技术为教学评估提供了强大支持，本创新在评估中应用了多种数智技术：

1. **学习分析技术应用**：
 - **学习行为数据采集**：通过学习管理系统采集学生学习行为数据，如学习时间、资源访问、互动参与等。
 - **学习轨迹可视化**：将学生学习数据转化为可视化图表和轨迹，直观展示学习过程和特征。
 - **预测性学习分析**：基于已有数据预测学生学习发展趋势和风险，及早发现问题并提供干预。

2. **人工智能辅助评估**：
 - **自动化评分系统**：利用AI技术对学生作业和测试进行自动评分，提高评估效率和客观性。
 - **文本分析技术**：运用自然语言处理技术分析学生文本作业，提取关键概念、分析逻辑结构。
 - **多模态内容分析**：利用AI技术分析学生创作的多模态内容，评价表达能力和创新水平。

3. **自适应评估系统**：
 - **个性化评估任务**：基于学生特点和学习进展自动生成个性化评估任务，提供精准评估。
 - **实时反馈系统**：在学习过程中提供即时评估反馈，促进学生自我调节和持续改进。
 - **智能推荐系统**：基于评估结果智能推荐学习资源和活动，支持个性化学习路径。

这些数智技术的应用，不仅提高了评估的效率和精准度，也拓展了评估的广度和深度，为教学决策和学生发展提供了有力支持。同时，数智技术的应用本身也是对学生数智素养的培养，实现了评估与教学的有机融合。

### 八、教学创新实施路径与保障

#### （一）分阶段实施路径

为确保教学创新的有效落地，本创新设计了分阶段实施路径：

1. **前期准备阶段（3个月）**：
 - **理论研究与方案完善**：深入研究数智时代认知特点和学生学习需求，细化教学创新方案。
 - **资源建设与技术准备**：开发多模态教学资源，搭建技术支持平台，确保资源和技术就绪。
 - **教师培训与试点准备**：开展教师能力培训，选定试点班级，进行学生前测和需求调研。

2. **实施推进阶段（一学期）**：
 - **初步实施与调整**：开展第一阶段教学活动，收集反馈，及时调整优化。
 - **深化实施与监测**：推进后续教学单元实施，加强过程监测和指导，开展中期评估。
 - **总结评估与成果凝练**：完成全部教学单元，开展总结性评估，整理教学创新成果。

3. **总结优化阶段（2个月）**：
 - **评估分析与经验总结**：全面分析教学效果数据，总结成功经验和存在问题。
 - **方案优化与推广准备**：基于实施经验优化教学方案，准备推广材料和活动。

这种分阶段实施路径，遵循"循序渐进、重点突破、持续优化"的原则，确保教学创新能够科学有序地实施，并在实践中不断完善和发展。

#### （二）多层次保障措施

为保障教学创新的顺利实施，本创新设计了多层次保障措施：

1. **组织保障**：
 - 成立教学创新领导小组，统筹协调各项工作
 - 建立专业教学团队，明确分工与责任
 - 设立技术支持团队，保障技术平台运行

2. **资源保障**：
 - 配置必要的硬件设施（多媒体教室、录播设备等）
 - 提供充足的软件资源（教学平台、创作工具等）
 - 保障教学创新的经费支持

3. **技术保障**：
 - 建立技术支持服务机制
 - 提供及时的技术培训和指导
 - 确保技术系统的稳定运行

4. **质量保障**：
 - 建立教学质量监控机制
 - 定期开展教学效果评估
 - 及时调整优化教学方案

5. **激励保障**：
 - 设立教学创新奖励机制
 - 提供教师专业发展支持
 - 营造创新教学文化氛围

这些多层次保障措施相互配合、协同作用，为教学创新的顺利实施提供了全方位支持，确保创新目标的实现和教学质量的提升。

#### （三）风险预警与应对

教学创新实施过程中可能面临各种风险和挑战，本创新设计了风险预警与应对机制：

1. **技术风险**：
 - **风险点**：技术平台不稳定或操作复杂，影响教学实施。
 - **预警指标**：系统故障率、用户反馈问题数。
 - **应对措施**：加强技术测试，提供技术支持，准备备用方案。

2. **教师适应风险**：
 - **风险点**：教师对新教学方式适应困难，影响教学效果。
 - **预警指标**：教师反馈问题，教学实施偏差。
 - **应对措施**：强化培训指导，建立教师互助机制，渐进式实施。

3. **学生接受风险**：
 - **风险点**：学生对新教学方式不适应，影响学习效果。
 - **预警指标**：学生参与度，学习满意度。
 - **应对措施**：加强学生引导，提供学习支持，灵活调整节奏。

4. **资源不足风险**：
 - **风险点**：教学资源开发不足或质量不高，影响教学实施。
 - **预警指标**：资源覆盖率，资源质量评价。
 - **应对措施**：优先保障核心资源，引入外部优质资源，建立资源共享机制。

5. **效果不佳风险**：
 - **风险点**：教学创新效果不达预期，影响推广应用。
 - **预警指标**：学习效果评估数据，对比分析结果。
 - **应对措施**：及时分析原因，调整教学策略，强化关键环节。

通过建立风险预警与应对机制，本创新能够及时发现和解决实施过程中的问题，确保教学创新的顺利推进和预期目标的实现。

# 数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新报告

## 结论

### 一、研究总结

本研究以"数智时代的认知重塑：《传播学引论》基模导向的多模态教学创新"为主题，面向双一流高校本科一年级新闻传播学专业的专业必修课《传播学引论》，探索了适应数智时代特点、促进学生认知重塑的教学创新路径。研究的主要内容和成果可总结如下：

1. **理论基础构建**：本研究深入分析了数智时代的特征与挑战、数字原住民的认知特点和传播学教学的时代挑战，系统阐述了基模理论的核心内涵及其在教学中的应用价值，探讨了多模态教学的理论基础和数智技术赋能教学的创新路径，为教学创新提供了坚实的理论支撑。

2. **创新框架设计**：本研究提出了"三维一体"教学模式、"四阶递进"教学流程和"双轨并行"评价体系，构建了系统化、立体化的教学创新框架。其中，"三维一体"教学模式整合了认知维度、模态维度和技术维度；"四阶递进"教学流程包括基模激活、基模重构、基模应用和基模迁移四个阶段；"双轨并行"评价体系融合了形成性评价和总结性评价两条轨道。

3. **课程内容重构**：本研究基于基模理论重构了《传播学引论》课程内容，形成了"核心基模+拓展模块"的螺旋式上升结构，实现了中西融合、古今贯通和理实结合，并采用多种模态呈现课程内容，创设了丰富的学习环境。

4. **教学活动设计**：本研究设计了基模激活型、基模重构型、基模应用型和基模迁移型四类教学活动，涵盖多模态情境导入、认知冲突设计、多模态知识建构、中西传播智慧对比、传播方案设计、多模态传播创作、跨情境传播实践、学科交叉项目等多种创新活动。

5. **评估方法创新**：本研究构建了多维度的评估内容体系，开发了多元化的评估方法，应用数智技术支持评估创新，实现了对学生认知发展、能力提升和情感态度的全面评价。

6. **实施路径规划**：本研究设计了分阶段实施路径，提出了多层次保障措施，建立了风险预警与应对机制，为教学创新的落地实施提供了可操作的指导方案。

7. **成效与推广分析**：本研究分析了教学创新在学生发展、教学质量、教师发展和学科建设方面的预期成效，探讨了教学创新的理论推广价值、实践推广价值和政策推广价值，并对未来发展进行了展望。

通过以上研究内容和成果，本研究构建了一套系统、科学、可行的《传播学引论》基模导向多模态教学创新方案，为数智时代传播学教学改革提供了新的思路和方法，为培养适应时代发展的高素质传播学人才做出了贡献。
