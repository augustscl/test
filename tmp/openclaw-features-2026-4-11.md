# 虾王当前最新版 OpenClaw 可用功能清单（2026.4.11）

这份文档整理的是本王当前在 OpenClaw 2026.4.11 环境里可直接调用的主要功能。

## 1. 当前版本
- OpenClaw 版本：2026.4.11
- 运行模型：openai-codex/gpt-5.4
- 运行环境：macOS / 主会话 main

## 2. OpenClaw 核心能力
### 2.1 会话与代理编排
- 当前主会话直接执行任务
- 创建子会话 / 子代理
- 向其他会话发送消息
- 查看其他会话历史
- 查看会话状态与模型信息
- 子代理管理

### 2.2 系统与网关控制
- Gateway 重启
- Gateway 配置读取 / 局部修改
- OpenClaw 自更新
- 定时任务（Cron）创建、修改、执行、查看运行记录

### 2.3 文件与工作区操作
- 读取文件
- 写入文件
- 精准编辑文件
- 批量补丁修改
- 执行 Shell 命令
- 管理后台运行进程

## 3. 联网与信息获取能力
### 3.1 网络搜索
- Web 搜索
- 网页正文抓取
- PDF 内容分析
- 图片内容识别

### 3.2 研究与资料处理
- 读取网页并提炼重点
- 读取 PDF 并做总结或分析
- 对图片进行结构化识别
- 支持结合本地文件和网络结果做汇总

## 4. 飞书 / Lark 生态能力
### 4.1 飞书文档
- 创建飞书文档
- 读取飞书文档
- 覆盖写入、追加、插入、定位更新文档
- 上传图片、文件到文档
- 表格写入与块级更新

### 4.2 飞书知识库与云盘
- 浏览知识空间
- 创建 Wiki 节点
- 移动 / 重命名知识库节点
- 查看云盘文件信息
- 创建文件夹、移动文件、删除文件
- 文档评论与回复评论

### 4.3 飞书多维表格（Bitable）
- 解析 Bitable URL
- 获取数据表元信息
- 列字段、列记录
- 读取单条记录
- 新增记录
- 更新记录
- 创建多维表格 App
- 创建字段

### 4.4 飞书聊天与通讯录侧
- 查询群信息
- 查询群成员
- 查询成员信息
- 向指定 Feishu 用户或群发送消息

## 5. 内容生产与多媒体能力
### 5.1 图片与音频
- AI 生图
- 图片分析
- 文本转语音

### 5.2 文档与素材处理
- 生成适合分享的结构化说明文档
- 从 PDF、图片、网页提取信息后再二次整理

## 6. 设备、画布与交互能力
### 6.1 Canvas
- 打开画布
- 跳转页面
- 执行页面脚本
- 截图快照

### 6.2 配对设备（Nodes）
- 查看设备状态
- 获取设备信息
- 推送通知
- 拍照、录像、录屏
- 读取位置
- 查看通知

## 7. 记忆与上下文能力
- 搜索长期记忆
- 读取指定记忆片段
- 结合记忆回答历史决策、偏好、长期规则

## 8. 当前已验证可用的重点链路
- OpenClaw 更新与重启：已验证
- Cron 管理：已验证
- Git / Shell / 文件编辑：已验证
- 飞书文档写入：可用
- Bitable 读写：可用

## 9. 适合现在直接拿来用的工作流
1. 飞书文档整理链路：信息收集 → 结构化整理 → 自动生成飞书文档
2. 飞书表格沉淀链路：资料整理 → 写入多维表格 → 后续检索 / 更新
3. 定时提醒链路：用 Cron 定时提醒到指定会话
4. 调研链路：搜索网页 / 读 PDF / 总结成文档
5. 编码执行链路：文件修改 → 命令执行 → 验证结果 → 汇报
